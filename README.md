# Smart Complaint Management System — Frontend

React + Vite + Leaflet.

## Run
```powershell
npm install
npm run dev
```

Open http://localhost:5173

Set `VITE_API_BASE_URL` in `.env` or `.env.local` if the backend is not on localhost:8080.

The UI includes:
- Maximalist-inspired citizen portal
- Glassmorphism admin console
- Floating ambient animations
- Free OpenStreetMap/Leaflet map
- Browser geolocation
- Complaint proof photo upload
- Admin proof preview modal
- Search/filter/status/assignment
